## Deskripsi
Repository ini berisi pengerjaan Ujian Tengah Semester (UTS) mata kuliah Machine Learning yang mencakup penerapan Linear Regression dan Logistic Regression menggunakan Python pada Jupyter Notebook.

## Dataset
1. **Ads_Data.csv**  
   Dataset untuk analisis Linear Regression dengan variabel:
   - `BiayaIklan`: biaya iklan sebagai variabel fitur.
   - `Penjualan`: nilai penjualan sebagai variabel target.

2. **Email_Data.csv**  
   Dataset untuk analisis Logistic Regression dengan variabel:
   - `JumlahLink`: jumlah tautan dalam email.
   - `KataPromo`: jumlah atau indikator kata promosi dalam email.
   - `Spam`: label klasifikasi email (1 = spam, 0 = bukan spam).
